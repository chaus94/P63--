Як працює рейтинг зірками

Рейтинг зроблено без JavaScript за допомогою HTML-радіокнопок і CSS.

1. Усі п'ять радіокнопок мають однакове name="rating", тому можна вибрати
   лише одну оцінку.
2. Кожна зірка — це елемент <label>. Атрибути for у label та id у radio
   пов'язують зірку з відповідною кнопкою.
3. Атрибут checked задає початкову оцінку — 4 з 5.
4. Радіокнопки приховані стилями CSS, але залишаються робочими.
5. CSS-селектор :checked ~ label підсвічує вибрану зірку та зірки
   ліворуч від неї. Під час наведення курсора рейтинг підсвічується
   для попереднього перегляду.

Щоб побачити рейтинг у браузері, відкрийте файл cards.html у папці
cards-rating-interactive.
