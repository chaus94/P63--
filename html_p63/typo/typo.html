що таке типографика*

Типографіка — це напрям графічного дизайну і система оформлення друкованого тексту. Вона, зокрема, передбачає вибір гарнітури, кеглю, довжини рядка, міжрядкового і міжсимвольного інтервалу. Мета типографіки  — зробити текст легким для сприйняття й привабливим, адже утримати увагу глядача у переповненому візуальним контентом світі може бути непростим завданням.

серед головними аспектами типографіки можно видилити чіткість, читабельність та естетика. Чіткість визначає, наскільки зручним є текст для сприйняття. Читабельність більше стосується легкості розуміння, а естетика відповідає за загальну привабливість шрифту чи комбінації шрифтів.

стани елементив

html - елементи можуть знаходитись у ризних станах:

  • hover - над елементов знаходиться курсор миши
  • active - елемент е вибраним (натиснення пробилу активуе його)
  • focus - на елементи фокус введення (друк з клавиатури передаеться на нього )
  • checked - для чекбоксив чи радиокнопок - стан "вибрано"
  • visited - для посилань по якиъ були переходи

для стилизации елементив у ризному стани у css задаються псевдокласи що завершуються двокрапкою та назвою стану наприклад button:hover {...}
