Як працює цей сайт

Сторінка створена за допомогою HTML і CSS. HTML задає структуру каталогу: заголовок, картки товарів, ціни та кнопки. CSS відповідає за кольори, розташування елементів і вигляд сторінки на різних екранах.

  • Картка товару містить фотографію, назву, опис і ціну.
  • Натисніть «До кошика», щоб позначити товар. Лічильник унизу каталогу показує кількість позначених товарів.
  • Натисніть на сердечко, щоб додати товар до обраного або прибрати його звідти.
  • Кнопки-перемикачі та лічильник зроблені засобами HTML і CSS — JavaScript не використовується.
  • На вузькому екрані картки автоматично перебудовуються в один стовпець.

Це навчальний каталог: вибрані товари не зберігаються після перезавантаження сторінки, а оформлення замовлення не виконується.
