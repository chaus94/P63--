Кольорове оформлення таблиці

Для оформлення рядків використано CSS-селектори tbody tr:nth-child(odd) і tbody tr:nth-child(even).

Приклади CSS-селекторів
Селектор Що вибирає Приклад
* Усі елементи на сторінці * { box-sizing: border-box; }
p Усі абзаци p { color: #334155; }
.note Елементи з класом note .note { background: #fff7cc; }
#title Елемент з ідентифікатором title #title { text-align: center; }
table td Усі комірки даних усередині таблиці table td { padding: 10px; }
tr:nth-child(even) Парні рядки таблиці tr:nth-child(even) { background: #e0f2fe; }
