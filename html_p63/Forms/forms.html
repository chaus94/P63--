Елементи HTML-форм

Форма об'єднує елементи для введення й вибору даних. У таблиці наведено приклади полів <input> та інших елементів форми. Спробуйте взаємодіяти з ними.

Приклади елементів форми
Елемент Для чого потрібен Приклад
input type="text" Звичайний однорядковий текст
input type="email" Електронна адреса з перевіркою формату
input type="password" Пароль; введені символи приховано
input type="tel" Номер телефону
input type="url" Вебадреса з перевіркою формату
input type="search" Поле для пошукового запиту
input type="number" Числове значення з кнопками зміни
input type="range" Вибір числа за допомогою повзунка
input type="date" Вибір дати
input type="time" Вибір часу
input type="datetime-local" Вибір дати й часу
input type="month" Вибір місяця та року
input type="week" Вибір тижня та року
input type="color" Вибір кольору
input type="file" Вибір файлу з пристрою
input type="checkbox" Прапорець для незалежного вибору
input type="radio" Один варіант із групи
Місто:
select Вибір зі списку
textarea Багаторядковий текст
input type="submit" Надсилання значень форми
input type="reset" Очищення та відновлення початкових значень
button Кнопка для виконання дії
