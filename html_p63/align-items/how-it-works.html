Як працює align-items

Розберімо, як Flexbox розташовує елементи, що означають його осі та як вибрати потрібне значення.

Перейти до наочних прикладів

КРОК 1

Створіть Flex-контейнер

Спочатку задайте батьківському елементу display: flex. Його безпосередні дочірні елементи стануть flex-елементами. 

.container {
  display: flex;
}

КРОК 2

Зрозумійте дві осі

Flexbox розкладає елементи вздовж основної осі. align-items вирівнює їх поперек неї — на поперечній осі. За стандартного flex-direction: row основна вісь горизонтальна, а поперечна — вертикальна.

Поперечна вісь ↕ Основна вісь  →

Якщо задати flex-direction: column, напрями зміняться: основна вісь стане вертикальною, а поперечна — горизонтальною. Тому align-items вже вирівнюватиме елементи зліва направо або справа наліво.

КРОК 3

Виберіть спосіб вирівнювання

  • stretch — розтягує елементи по поперечній осі, якщо для них не задано власний розмір у цьому напрямі. Це значення за замовчуванням.
  • flex-start — притискає елементи до початку поперечної осі.
  • center — розміщує елементи по центру поперечної осі.
  • flex-end — притискає елементи до кінця поперечної осі.
  • baseline — вирівнює текст за його базовою лінією.

КРОК 4

Зв’яжіть CSS із результатом

У прикладах на цій сторінці спільний клас задає Flexbox-контейнер і його висоту, а окремий клас визначає значення align-items: 

.flex-demo {
  display: flex;
  height: 154px;
}

.align-center {
  align-items: center;
}

Висота контейнера дає елементам простір для вирівнювання. У варіантах із flex-start, center, flex-end та baseline елементи мають різну висоту, щоб результат було видно. У прикладі stretch висоту елементів не задано, тож вони заповнюють доступну висоту контейнера.

i

Коротко: align-items вирівнює flex-елементи поперек основної осі. Для вирівнювання вздовж основної осі зазвичай використовують justify-content.
